Museum website plan: 
-----------------------------------------------------

Search option: 
- Browse available tours/events
  
Booking and reservations: 
- Real-time availability 
- ticket booking (E-tickets)
- Quantity booking options 
- Booking confirmation 'email'
  
User Accounts:  
- Create/login account 
- View booking history (tickets) 
- Modify bookings (dates)
- Save favourite tours/events

Tour/Events Details Pages: 
- Descriptions 
- Duration 
- Bookings
- Availability
- Save/Favourite 

Visitor Information: 
- Opening hours 
- Location
- Accessibility
- FAQs
- Food
- Services
